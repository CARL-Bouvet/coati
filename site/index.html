Ask your own AI model about the page you are on.

Coati opens a side panel in your browser. You connect a model you choose, on your computer with Ollama or LM Studio, or online with your own API key. Then ask it to summarise an article or a YouTube video, explain the page, or search the web for you.

Add to Chrome Source code on GitHub

How it works

The extension and the local program run on your computer. The model runs where you choose.

  1. In your browser

    The extension

    A side panel for Chrome, Chromium, Brave, Edge and Firefox. The model reads the page only when your question needs it, and every answer says whether the page was read.

  2. On your computer

    The local program

    A small program that keeps your API keys and talks to the model. It listens on 127.0.0.1 only and accepts only the paired extension.

  3. Local or online

    Your model

    Ollama or LM Studio on your machine, or your own key for Claude, OpenAI, Mistral, OpenRouter, DeepSeek or any OpenAI-compatible address. Coati ships no AI.

Download

Add the extension from the Chrome Web Store (Chrome, Brave, Edge, Chromium). Its first-run tutorial shows which file of the local program your system needs, for Windows, macOS or Linux.

The latest release has the local program and the Firefox extension, to load as a temporary add-on. The files are not signed with a paid developer certificate, so your system warns you once.

Privacy

Coati has no server of its own and sends no telemetry. Page content leaves your computer only when you use an online model, and then goes to that provider.

Coati never reads password fields. On a page it only reads and highlights: it never clicks, types, pays, sends, deletes, publishes or signs in.
