# Coati logo

- `coati.svg`: the logo, a faceted coati head. Works on light and dark backgrounds.
- `coati-512.png`: the same, 512 px, transparent background.
- `github-1280x640.png`: the repository's social preview image.
- `police/`: Figtree, the font used next to the logo, with its OFL licence.

The extension's toolbar icons are in `extension/icons/`.
